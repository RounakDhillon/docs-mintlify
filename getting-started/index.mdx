## How Collate helps Data Teams?

Collate is a complete package for data teams to break down team silos, share data assets from multiple sources securely, collaborate around data, and build a documentation-first data culture in the organization.

- [Discovery](/how-to-guides/data-discovery): Integrated catalog, quality, and glossary; natural language search, filtering, and faceting, 100+ turnkey data connectors, and Collate AI Chatbot.

- [Lineage](/how-to-guides/data-lineage): Table and column-level lineage, automated data estate mapping and APIs, lineage layers and search, governance and PII automation and manual customization.

- [Observability](/how-to-guides/data-quality-observability): Alerting and notifications, incident management, third-party notifications, pipeline monitoring, root cause analysis, anomaly detection, data profiler.

- [Quality](/how-to-guides/data-quality-observability/quality): Table and column test cases, no-code and SQL data quality tests, test suites, test case reporting, quality dashboards, widgets, and data quality lineage maps.

- [Collaboration](/how-to-guides/data-collaboration): Knowledge center, announcements and tasks, Slack/Teams integration, team conversations, activity feed, and team dashboards.

- [Governance](/how-to-guides/data-governance): Business glossary, classification tags, automated PII classification and description generation, data stewardship dashboards, and metadata automations.

- [Insights](/how-to-guides/data-insights): Data assets, app analytics, coverage KPIs, ownership dashboards, data health reports, governance reports, cost optimizer, custom dashboards, and widgets.
