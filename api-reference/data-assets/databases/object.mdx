## Required Fields

<ResponseField name="id" type="uuid">
  Unique identifier for the database. **Auto-generated by the server** - do not provide when creating.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of the database. Must be unique within the parent service. Pattern: `^[^.]*$`, length 1-256 characters.
</ResponseField>

<ResponseField name="service" type="EntityReference" required>
  Reference to the parent DatabaseService. Provide the service name when creating.
</ResponseField>

## Core Identity Properties

<ResponseField name="fullyQualifiedName" type="string">
  Fully qualified name in format `{service}.{database}`. **Auto-generated by the server**.
</ResponseField>

<ResponseField name="displayName" type="string">
  Human-readable display name for the database.
</ResponseField>

<ResponseField name="description" type="markdown">
  Rich text description of the database in Markdown format.
</ResponseField>

## Operational Properties

<ResponseField name="default" type="boolean" default="false">
  Whether this is the default database for the service. Some databases (like MySQL) don't support a database/catalog hierarchy and use a default database.
</ResponseField>

<ResponseField name="deleted" type="boolean" default="false">
  Whether the database has been soft-deleted. **Auto-managed by the server**.
</ResponseField>

<ResponseField name="retentionPeriod" type="duration">
  Data retention period in ISO 8601 duration format (e.g., `P365D` for 365 days, `P1Y` for 1 year).
</ResponseField>

<ResponseField name="sourceUrl" type="string">
  URL to the database in the source system.
</ResponseField>

## Relationship Properties

<ResponseField name="serviceType" type="databaseServiceType">
  Type of the parent database service (e.g., Snowflake, BigQuery, Postgres). **Auto-populated by the server**.
</ResponseField>

<ResponseField name="databaseSchemas" type="EntityReference[]">
  References to child schemas within this database. **Read-only**, populated when requesting with `fields=databaseSchemas`.
</ResponseField>

<ResponseField name="location" type="EntityReference">
  Reference to the storage location for this database.
</ResponseField>

## Governance Properties

<ResponseField name="owners" type="EntityReference[]">
  Owner users or teams. Inherited by all child schemas and tables.
</ResponseField>

<ResponseField name="domain" type="EntityReference">
  Business domain this database belongs to. Inherited by all child entities.
</ResponseField>

<ResponseField name="dataProducts" type="EntityReference[]">
  Data products this database is associated with.
</ResponseField>

<ResponseField name="tags" type="TagLabel[]" default="[]">
  Classification tags applied to this database.
</ResponseField>

<ResponseField name="followers" type="EntityReference[]">
  Users following this database for updates.
</ResponseField>

<ResponseField name="votes" type="Votes">
  Upvotes and downvotes from users.
</ResponseField>

<ResponseField name="lifeCycle" type="LifeCycle">
  Entity lifecycle metadata including creation and access timestamps.
</ResponseField>

<ResponseField name="certification" type="AssetCertification">
  Certification status (e.g., Bronze, Silver, Gold).
</ResponseField>

## Usage & Profiling

<ResponseField name="usageSummary" type="UsageDetails">
  Daily, weekly, and monthly usage statistics. **Auto-populated by usage ingestion**.
</ResponseField>

<ResponseField name="databaseProfilerConfig" type="DatabaseProfilerConfig">
  Profiler configuration with settings:
  - `profileSample`: Sample percentage for profiling
  - `profileSampleType`: Sampling type (PERCENTAGE or ROWS)
  - `sampleDataCount`: Number of sample rows (default: 50)
  - `samplingMethodType`: Sampling method (BERNOULLI or SYSTEM)
</ResponseField>

## Versioning Properties

<ResponseField name="version" type="number">
  Entity version number. **Auto-incremented by the server** on each update.
</ResponseField>

<ResponseField name="updatedAt" type="timestamp">
  Last update timestamp in Unix epoch milliseconds. **Auto-managed by the server**.
</ResponseField>

<ResponseField name="updatedBy" type="string">
  User who last updated the entity. **Auto-managed by the server**.
</ResponseField>

<ResponseField name="changeDescription" type="ChangeDescription">
  Details of changes made in the current version. **Auto-managed by the server**.
</ResponseField>

## Extension Properties

<ResponseField name="extension" type="object">
  Custom properties defined for this entity type.
</ResponseField>
