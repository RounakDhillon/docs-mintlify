A **Database Schema** organizes tables within a database. It's the direct parent of tables in the entity hierarchy.

<Info>
Entity schema follows the [OpenMetadata Standard](https://openmetadatastandards.org/metadata-specifications/entities/database-schema/).
</Info>

## Entity Hierarchy

Schemas sit between Databases and Tables in the hierarchy:

```
DatabaseService
└── Database
    └── DatabaseSchema (this page)
        └── Table
```

## Inheritance

When you set an **owner** or **domain** on a Database Schema, it is inherited by all child tables.
