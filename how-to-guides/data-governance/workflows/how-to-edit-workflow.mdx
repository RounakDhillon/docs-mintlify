# Governance Workflows - How to Edit

This is a small How-To guide to help you understand how to easily edit the workflow configurations.

## Edit Trigger

1. Click on the **Configuration** tab

<img src="/images/how-to-guides/governance/workflows-how-to-edit-configuration.png" alt="how-to-edit-configuration-click" />

2. Edit the needed fields and **Save**

<img src="/images/how-to-guides/governance/workflows-how-to-edit-configuration-page.png" alt="how-to-edit-configuration-page" />

## Edit Nodes

1. Click on the **Workflow** tab

<img src="/images/how-to-guides/governance/workflows-how-to-edit-workflow.png" alt="how-to-edit-workflow" />

2. Click on the **Node** that you wish you edit

<img src="/images/how-to-guides/governance/workflows-how-to-edit-node-click.png" alt="how-to-edit-node-click" />

3. Edit the needed fields and **Submit**

<img src="/images/how-to-guides/governance/workflows-how-to-edit-node-page.png" alt="how-to-edit-node-page" />
