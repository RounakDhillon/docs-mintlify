# Collate AI SQL Agent

Quickly understand and improve the performance of the queries that are executed in your system via a chat interface!

## Key Features

- Query explanation and breakdown
- Query performance improvements

<img src="/public/images/collate-ai/collate-ai-sql-agent-feature.png" alt="Ask Questions related to SQL Queries" />

## Setup Instructions

1. Open a Database

- Navigate to the database section in the platform.

- Open any database.

<img src="/public/images/collate-ai/collate-ai-sql-agent.png" alt="Open a Database" />

Example: In our case, we opened Customers.

2. Go to the Queries Tab

Inside the database view, locate and click the Queries tab.

<img src="/public/images/collate-ai/collate-ai-sql-agent1.png" alt="Go to the Queries Tab" />

3. Click the Ask Collate Icon

In the Queries tab, click on the Ask Collate icon.

<img src="/public/images/collate-ai/collate-ai-sql-agent2.png" alt="Click the Get Collate Icon" />

4. Redirect to Ask Collate

After clicking the icon, you will be redirected to the Ask Collate interface.

<img src="/public/images/collate-ai/collate-ai-sql-agent-feature.png" alt="Ask Questions related to SQL Queries" />

5. Ask Anything Related to SQL Queries

In Ask Collate, type your question or request.

You can ask anything related to SQL query creation, optimization, explanations, or filters.

<img src="/public/images/collate-ai/collate-ai-sql-agent-feature.png" alt="update or suggest tiers" />

## Setup Instructions

1. **Navigate to Applications**: Go to `Settings > Applications`.

<img src="/public/images/collate-ai/collate-ai-agent.png" alt="setting up Collate AI" />

2. **Install the Agent**: Click on "Add Apps" to access the marketplace and install the Collate AI Tier Agent.

<img src="/public/images/collate-ai/collate-ai-sql-agent-feature.png" alt="Installation" />

3. **Configure the Agent**:
   - **Filter**: Use the UI Query Filter builder to select assets for tier classification.
   - **Patch Tier If Empty**: Enable this option to automatically assign a tier to assets that currently lack one.

<img src="/public/images/collate-ai/collate-ai-tier-agent1.png" alt="Configuration" />

4. **Scheduling**: Set up regular intervals for the agent to run and update metadata.

<img src="/public/images/collate-ai/collate-ai-tier-agent2.png" alt="Scheduling" />
