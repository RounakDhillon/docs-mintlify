## Metadata Ingestion

All connectors are defined as JSON Schemas.
[Here](https://github.com/open-metadata/OpenMetadata/blob/main/openmetadata-spec/src/main/resources/json/schema/entity/services/connections/pipeline/mulesoftConnection.json)
you can find the structure to create a connection to Mulesoft.

In order to create and run a Metadata Ingestion workflow, we will follow
the steps to create a YAML configuration able to connect to the source,
process the Entities if needed, and reach the Collate server.

The workflow is modeled around the following
[JSON Schema](https://github.com/open-metadata/OpenMetadata/blob/main/openmetadata-spec/src/main/resources/json/schema/metadataIngestion/workflow.json)

```yaml
source:
  type: mulesoft
  serviceName: local_mulesoft
  serviceConnection:
    config:
      type: Mulesoft
      hostPort: https://anypoint.mulesoft.com
      # Basic Authentication
      authentication:
        username: your_username
        password: your_password
      # OR OAuth 2.0 Connected App Authentication
      # authentication:
      #   clientId: your_client_id
      #   clientSecret: your_client_secret
      organizationId: your_organization_id  # Optional
      environmentId: your_environment_id    # Optional
      # pipelineFilterPattern:
      #   includes:
      #     - sales-.*
      #   excludes:
      #     - test-.*
```

### Authentication Examples

#### Basic Authentication Configuration

```yaml
source:
  type: mulesoft
  serviceName: mulesoft_anypoint
  serviceConnection:
    config:
      type: Mulesoft
      hostPort: https://anypoint.mulesoft.com
      authentication:
        username: admin@yourcompany.com
        password: your_secure_password
      organizationId: abc123-def456-ghi789
```

#### OAuth 2.0 Connected App Configuration

```yaml
source:
  type: mulesoft
  serviceName: mulesoft_anypoint
  serviceConnection:
    config:
      type: Mulesoft
      hostPort: https://anypoint.mulesoft.com
      authentication:
        clientId: your_connected_app_client_id
        clientSecret: your_connected_app_client_secret
      organizationId: abc123-def456-ghi789
      environmentId: production-env-id
```

#### EU Cloud Configuration

```yaml
source:
  type: mulesoft
  serviceName: mulesoft_eu
  serviceConnection:
    config:
      type: Mulesoft
      hostPort: https://eu1.anypoint.mulesoft.com
      authentication:
        username: admin@yourcompany.com
        password: your_secure_password
```
