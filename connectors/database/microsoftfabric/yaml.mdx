## Metadata Ingestion
All connectors are defined as JSON Schemas.
[Here](https://github.com/open-metadata/OpenMetadata/blob/main/openmetadata-spec/src/main/resources/json/schema/entity/services/connections/database/microsoftFabricConnection.json)
you can find the structure to create a connection to Microsoft Fabric.
In order to create and run a Metadata Ingestion workflow, we will follow
the steps to create a YAML configuration able to connect to the source,
process the Entities if needed, and reach the Collate server.
The workflow is modeled around the following
[JSON Schema](https://github.com/open-metadata/OpenMetadata/blob/main/openmetadata-spec/src/main/resources/json/schema/metadataIngestion/workflow.json)

### Configuration Examples
#### Basic Configuration
```yaml
source:
  type: microsoftfabric
  serviceName: fabric_prod
  serviceConnection:
    config:
      type: MicrosoftFabric
      hostPort: your-workspace.datawarehouse.fabric.microsoft.com:1433
      clientId: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
      clientSecret: your_client_secret_value
      tenantId: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```
#### Single Warehouse with Schema Filtering
```yaml
source:
  type: microsoftfabric
  serviceName: fabric_analytics
  serviceConnection:
    config:
      type: MicrosoftFabric
      hostPort: your-workspace.datawarehouse.fabric.microsoft.com:1433
      clientId: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
      clientSecret: your_client_secret_value
      tenantId: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
      database: SalesWarehouse
      schemaFilterPattern:
        includes:
          - sales_.*
          - marketing_.*
        excludes:
          - ^db_.*
          - ^sys$
          - ^information_schema$
      tableFilterPattern:
        includes:
          - fact_.*
          - dim_.*
```
#### Ingest All Warehouses and Lakehouses
```yaml
source:
  type: microsoftfabric
  serviceName: fabric_all
  serviceConnection:
    config:
      type: MicrosoftFabric
      hostPort: your-workspace.datawarehouse.fabric.microsoft.com:1433
      clientId: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
      clientSecret: your_client_secret_value
      tenantId: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
      ingestAllDatabases: true
      databaseFilterPattern:
        includes:
          - prod_.*
          - analytics_.*
        excludes:
          - test_.*
          - dev_.*
```
