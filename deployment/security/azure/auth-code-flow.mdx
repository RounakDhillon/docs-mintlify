# Auth Code Flow


### Step 1: App Registrations

- Provide an Application Name for registration.
- Provide a redirect URL as a Auth Code Flow. 
- Click on Register.

<img src="/images/deployment/security/azure/create-web-registration.png" alt="create-app" />



### Step 2: Where to Find the Credentials

- The `Client ID` and the `Tenant ID` are displayed in the Overview section of the registered application.

<img src="/images/deployment/security/azure/web-client-secret.png" alt="create-app" />

- When passing the details for `authority`, the `Tenant ID` is added to the URL as shown in the example
  below. `https://login.microsoftonline.com/TenantID`

```commandline
"authority": "https://login.microsoftonline.com/c11234b7c-b1b2-9854-0mn1-56abh3dea295"
```
